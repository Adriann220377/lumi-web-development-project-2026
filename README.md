# Lumi Architecture Studio — Web Development Project (2026)

A multi‑page responsive website built for the fictional **Lumi Architecture Studio** as part of the **Arcada Web Development course (Autumn 2026)**.  
Designed fully in **Figma** and implemented using **modern HTML5/CSS3**, with a clean Nordic minimalist aesthetic inspired by contemporary Scandinavian architecture.

---

## 📌 Project Overview

This project demonstrates a complete front‑end website build, including:

- A fully designed Figma prototype  
- A responsive multi‑page layout  
- A custom design system (colors, typography, spacing)  
- Interactive components (hamburger menu, animations, overlays)  
- Clean semantic HTML structure  
- Organized CSS architecture  
- Mobile‑first responsiveness  

---

## 🧩 Pages Included

- **Home** — Hero section, fade‑in animation, custom scrollbar, responsive navbar  
- **Projects** — Grid layout for featured architectural works  
- **About** — Studio philosophy, team, and brand identity  
- **Services** — Overview of architectural disciplines  
- **Contact** — Form layout + location details  
- **Web Report** — Full HTML-based documentation for the course submission  

---

## 🎨 Design System

- **Colors:** Nordic-inspired palette (Black, Charcoal, Gold, White, Muted Grey)  
- **Typography:** Montserrat (headings) + Inter (body)  
- **Layout:** Strong grid system, geometric spacing, clean section dividers  
- **Components:**  
  - Gold accent lines  
  - Hover overlays  
  - Thin animated scrollbar  
  - Responsive hamburger → X animation  

---

## 📱 Responsiveness

The site is fully responsive across:

- Desktop  
- Tablet  
- Mobile  

With a mobile-first navbar that switches to a hamburger menu and slide-out panel.
